> **This project is retired.**
>
> As of rubytest 0.10.0 (2026-11), the TAP, TAP-Y and TAP-J reporters are
> built into [rubytest](https://github.com/rubyworks/rubytest): select them
> with `rubytest -f tap`, `-f tapy` (or `-y`) and `-f tapj` (or `-j`). This
> gem is no longer needed.
>
> This repository preserves rubytest-tap, last released as 0.1.0 in 2014. It
> is no longer maintained.
